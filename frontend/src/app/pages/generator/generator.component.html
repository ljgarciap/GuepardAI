Build Your Prompt

A strong prompt = Objective + Tone + Audience + Slide type + Story + Visual rules + Output format.

How to write a good prompt
  • Objective — what is this presentation for? e.g. "CEO Board Update on Q3 performance".
  • Tone — Factual, engaging, optimistic, sense of urgency, financial...
  • Audience — Internal team, Board, CEO, client...
  • Slide type — cover, data grid, pillars, case study...
  • Story — customer-centric, creative, data-driven narrative...
  • Visual rules — use only library assets, use external assets, no restrictions...
  • Output format — data driven, storytelling, creative, action oriented...
  • Avoid buzzwords — be specific instead of generic corporate language.
